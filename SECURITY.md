# Security and responsible reporting

Agent Orchard is an independent, **unaudited** community smart-contract game. It is not a Binance product. Each on-chain state-changing action requires native BNB gas and a user-approved transaction.

- Never send the maintainers a seed phrase, private key, API key, session token or recovery code.
- Do not rely on a copied prompt or a public wallet lookup as authorization to transact.
- Treat the verified deployed BscScan source and independent transaction simulation as authoritative; if they disagree with the website, stop.
- If you identify a security issue, do **not** post exploitable wallet or credential data in a public issue. Contact project maintainers privately using an established channel once one is published.
- No bug bounty or formal security audit is represented by this file.
