# Agent Orchard — Innovation Award Judging Matrix

Official criteria: Agent ID Application Depth **30%**, Practicality & Feasibility **25%**, Product Completion **25%**, Innovation **20%**. This is the organizer's scoring framework, NOT a claim of any actual awarded score.

| Criterion | What Agent Orchard can demonstrate | Evidence still needed |
|---|---|---|
| Agent ID Application Depth (30%) | `onlyAgent` on five state-changing functions checks registry `balanceOf(msg.sender)>0`; on-chain verified `.ai` handle in leaderboard | Verified deployed source, positive and negative Agent ID gate demonstrations |
| Practicality & Feasibility (25%) | Short daily nonfinancial user journey; AI Pro task instructions; transparent user-borne gas fees; Cloudflare deployment | Real-user onboarding recordings and gas estimates; user feedback |
| Product Completion (25%) | Live site, Mainnet contract, responsive animated garden, event-indexed leaderboard and streak badges | Complete live check-in → plant → tend → harvest → mint receipts; Github repo; current screenshot |
| Innovation (20%) | Identity-bound orchard history, multi-day proofs, visual robot feedback, readable `.ai` handles with public data integrity | Clear demonstration of what differs from a regular points website and from trading agents |

## Notes
- The 30 unique Agent ID addresses interacting with the submission contract during the campaign are a **threshold to qualify for Innovation judging**; it is not itself a score.
- The Pioneer Award separately considers metrics such as interacting Agent ID addresses and transaction count or volume.
- Neither website views nor repeated transactions from one address replace distinct Agent ID-holding wallet participation.
- Project awards and community rewards are subject to the organizer's complete rules and decisions.
